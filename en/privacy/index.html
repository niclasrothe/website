Overview

This website is purely informational. It has no contact form, no comment function and no user accounts. It sets no cookies itself and uses no analytics or tracking services, no advertising and no embedded content from third parties. Fonts are not loaded from external servers. They come from your own device or are delivered directly by this website.

Hosting on GitHub Pages

This website is served via GitHub Pages. According to GitHub, the providers and data controllers for the data processed there are:

GitHub B.V., Prins Bernhardplein 200, 1097 JB Amsterdam, Netherlands, and
GitHub, Inc., 88 Colin P. Kelly Jr. St., San Francisco, CA 94107, USA

When you visit the website, GitHub processes technical connection data, in particular visitors' IP addresses. GitHub states that this data is logged and stored for the security of the service, regardless of whether visitors are signed in to GitHub. I do not analyse this data. The retention period is set by GitHub. Further details are in GitHub's privacy statement.

The legal basis is Art. 6(1)(f) GDPR. My legitimate interest is the secure and reliable provision of this website by a professional provider.

Data transfers to the USA

GitHub also processes data in the USA. According to GitHub, transfers from the EU rely on the EU-US Data Privacy Framework, under which GitHub is certified (adequacy decision of the European Commission, Art. 45 GDPR), as well as on the standard contractual clauses published by the European Commission (Art. 46 GDPR).

External links

The home page contains a link to my LinkedIn profile. It is an ordinary link and not an embedded feature. No data is transmitted to LinkedIn when you open this page. You only leave my website once you click the link. LinkedIn's privacy policy then applies.
